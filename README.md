# 자유의 여신상 XR 탐험대 — 미션 수행형 XR 실습

VR, AR, MR 체험을 **세 가지 미션**으로 연결한 스마트폰 중심 웹 학습 프로젝트입니다. 별도 앱 설치 없이 GitHub Pages에서 미션 화면을 실행할 수 있습니다. 단, AR/MR 기능은 지원 기기와 브라우저, 카메라 권한이 필요합니다.

## 학습 구성

1. **미션 1 · VR:** 360° 자유의 여신상 탐험 후 관찰 문제 풀기
2. **미션 2 · AR:** 자유의 여신상 인식 이미지로 설명판과 여행 영상을 확인하고 위치 퀴즈 풀기
3. **미션 3 · MR:** 현실 공간에 3D 여신상을 배치하고 손가락으로 크기·방향 조작 후 완료 체크

모든 미션을 완료하면 진행률 100%와 인쇄 가능한 탐험 인증서가 나타납니다. 진행 상황은 현재 브라우저의 로컬 저장소에 저장됩니다.

## 파일

- `index.html` : 전체 미션 화면, 퀴즈, 진행률, 완료 인증서
- `README.md` : 프로젝트 소개와 배포 안내

## 기존 XR 체험 주소 연결 (중요)

`index.html` 맨 아래 `<script>` 내부의 `LINKS` 값을 실제 배포 주소로 바꿔 주세요.

```javascript
const LINKS = {
  arPanel: 'https://실제-설명판-AR-주소/',
  arVideo: 'https://실제-영상-AR-주소/',
  mr: 'https://실제-MR-주소/'
};
```

VR은 기존에 공개된 `https://ilmac-knu.github.io/statue-liberty-vr/` 주소로 연결되어 있습니다. 이 URL은 기존 사이트에 접속하기 위한 **기술적 주소**이며 화면이나 설명문에 단체 이름을 표시하지 않습니다.

**주의:** AR 설명판, AR 영상, MR 주소는 확인되지 않아 기본값이 비어 있습니다. 실제 주소를 입력하기 전에는 해당 버튼 대신 설정 안내가 나옵니다. 미션 화면은 별도 체험을 직접 실행했는지 기술적으로 검증하지 않으며, 문제 정답 또는 사용자 체크로 완료 여부를 기록합니다.

## GitHub Pages 배포

1. GitHub에서 `statue-liberty-mission-xr` 공개 저장소를 생성합니다.
2. 저장소 최상위에 `index.html`, `README.md`를 업로드합니다.
3. **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
5. 배포가 완료되면 `https://ilmac-knu.github.io/statue-liberty-mission-xr/`에 접속합니다.

## 사용 방법

1. VR 미션의 체험 링크를 열고 관찰 문제를 풉니다.
2. AR 미션의 설명판·영상 체험 링크를 열고 퀴즈를 풉니다.
3. MR 미션의 배치 체험을 마치고 두 항목을 체크합니다.
4. 탐험 완료 화면에서 인증서를 인쇄하거나 PDF로 저장합니다.

## 구현 범위

이 저장소는 기존 VR·AR·MR 콘텐츠를 새로 제작하거나 하나의 3D 엔진으로 합치는 프로젝트가 아니라, **이미 제작된 개별 XR 콘텐츠를 미션형 학습 경험으로 연결하는 웹페이지**입니다. 각 체험은 새 탭에서 실행됩니다. 퀴즈와 체크 항목은 학습 확인 기능이며 XR 기기의 동작을 자동으로 판정하지 않습니다.
